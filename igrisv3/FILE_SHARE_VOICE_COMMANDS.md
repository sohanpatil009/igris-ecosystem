## 📋 Command Patterns

### Pattern Recognition
IGRIS understands various command patterns:

1. **Action + Target**
   - "Send file to John"
   - "Share with laptop"

2. **Question Format**
   - "Can I send files to John?"
   - "Is Sarah's phone available?"

3. **Imperative**
   - "Open file share"
   - "Show devices"

4. **Natural Conversation**
   - "I want to share some files"
   - "Help me send this to John"

## 🔧 Implementation Notes

### Plugin Integration
These commands will be processed by:
1. **NLU Engine** - Intent recognition
2. **File Share Plugin** - Command execution
3. **UI Components** - Visual feedback

### Command Priority
1. Security commands (accept/reject) - Highest
2. Transfer operations (send/receive)
3. Discovery (scan/list)
4. Settings (enable/disable)
5. Information (status/help) - Lowest

### Error Handling
- Device not found → "I couldn't find that device"
- Transfer failed → "Transfer failed: [reason]"
- Service offline → "File share service is not running"
- No files selected → "Please select files first"
